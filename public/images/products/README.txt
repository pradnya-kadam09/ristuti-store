REAL PRODUCT PHOTOS
-------------------
To show a real photo for a product, save it in this folder and name it with the product id:

   7.jpg     -> product 7
   25.png    -> product 25
   130.webp  -> product 130

You can find each product's id in data/products.json.
Restart the server (Ctrl + C, then npm start) and the photo replaces the drawn picture.
Photos work best in portrait shape (3:4), for example 900 x 1200 pixels.
